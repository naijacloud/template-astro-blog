This blog is a folder of Markdown files. Each file in `src/content/posts` is a post: the frontmatter holds the title, date and tags, and the rest is the post.

## Writing a post

Add a file, commit it and redeploy. Tag pages, the RSS feed and the sitemap update themselves.

```sh
touch src/content/posts/my-next-post.md
```
